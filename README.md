# Resonote downloads

Installers for the Resonote desktop app: voice typing in Indian languages and English, in every app.
Download from the website: https://resonote-rosy.vercel.app/download

| File | For |
|---|---|
| `Resonote-mac-apple-silicon.dmg` | Mac with an Apple chip (M1 or newer) |
| `Resonote-mac-intel.dmg` | Mac with an Intel chip |
| `Resonote-windows-setup.exe` | Windows 10 or 11 |
| `Resonote-linux.AppImage` | Linux (x64) |

The app is in early access and not yet signed with an Apple Developer ID or a Windows certificate,
so the first time you open it your computer asks you to confirm.

This repository holds only the installers. The source code is private.
